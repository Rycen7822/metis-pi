# 0.9.0 逻辑选区复制 — 最小实施计划

## 基线（已核对 2026-09-11）

- 插件 0.8.8 @ 4185395（干净）；Pi dev-dep 0.85.1 = 运行宿主 0.85.1。
- `pi-copy-soft-wrap` 0.1.2 **仍在用户 Pi 中加载**（`pi list` 实测，位于本插件之前）。其机制：包装
  `TuiAltScreen.prototype.getActiveSelectionText`，对输出做启发式 `unwrapVisualLines`。

## 根因（已读宿主 dist 源码核实）

`TuiAltScreen.getActiveSelectionText()`（tui-alt-screen.js L1189-1210）：按屏幕/内容行逐行
`stripTerminalSequences(sliceByColumn(...)).trimEnd()` 后 `join("\n")` —— 软折行变真换行、行尾空白丢失。
软换行由 Text/Markdown/列表/引用各层 `wrapTextWithAnsi` 引入；`hasActiveSelection()` 依赖同一序列化（P03）。
剪贴板通道 = 实例注入的 `copySelection` 回调（copyTextToClipboard L1217-1230）。

## 架构

**序列化点替换（实例级）**：把 `getActiveSelectionText` 换成实例属性，遮蔽原型链（旧插件的 prototype
包装对本实例失效，与加载顺序无关）。选区几何（getSelectionBounds/getSelectionColumns）保持宿主原生。

**Provenance 生成（渲染时）**：所有 product 以"它标注的确切 lines 数组"为键存 WeakMap —— 数组身份即
帧绑定（§10.1），包装器/重绘/放弃帧天然安全。包装层次：

1. `Text.prototype.render` / `Markdown.prototype.render`：复刻宿主管线生成带来源映射的行，并与宿主
   真实输出逐行 diff —— 不一致则不挂 product（自动降级 native 提取）。Markdown 复刻 = lexer（marked
   18.0.5 + 复刻 StrictStrikethrough/latex 扩展）+ renderToken 结构镜像（inline 层直接调宿主实例方法，
   ANSI 剥离即可见文本）。表格/未知 token → unknown 行回退。
2. `Box.prototype.render` / `Container.prototype.render`：行对齐 product（子数组引用+行偏移+列偏移），
   高度与 mouseLayout 校验。MouseRegion 等透传 wrapper 由数组身份自动解析。
3. 自有 renderer（shell/diff/write/rail）：在组件内直接产出 product。

**CopyRow 模型**：`spans[{colStart,colEnd,kind,text?}]`，`breakBefore: hard|soft|paragraph|gap|unknown`，
soft 断点的 `bridge`（被消费的空白，如 EN 空格；CJK 为空）。kind: content/decoration/semantic/gap/unknown。
列表 marker、引用首行边框、diff 符号、围栏 = semantic（选中才复制）；gutter/rail/padding/行号 = decoration。

**Ctrl+C 分流**：CodexSurfaceEditor.handleInput 覆盖 —— 选区存在且匹配 `keybindings` 的 app.clear 键
→ 同步快照序列化 → 有内容则 copyTextToClipboard（复用宿主回调+flash），消费按键；空（纯装饰）→ 只消费；
无选区 → 原生（双击退出/清空草稿逻辑不变）。焦点在模态时编辑器收不到键（天然让位）。Ctrl+X 与
copy-on-select 走同一序列化点自动获得精确文本。

## 非目标

不重装 Zentui；不改 Working/工具执行/session 数据；不建 clip.exe/OSC52 平台层；不卸载用户旧插件
（README 给出迁移步骤）；表格单元格级映射（回退 native）；跨 resize 选区重投影（无法安全重投影时清空）。

## 风险

- 宿主升级导致 Markdown 管线漂移 → 逐行 diff 失败自动降级 + /codex-ui 报告原因。
- 双重渲染成本（对齐 pass 重放子 render）：宿主叶子组件均有内部缓存，仅容器每帧多一次 O(children)。
- 旧插件：本插件实例补丁优先生效；`/codex-ui` 检测并报告其存在，README 建议停用。
