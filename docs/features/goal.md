# 长任务目标

目标保存在当前会话分支中。目标处于 `active` 时，Pi 在回合结束后按需续跑；暂停不会取消当前回复。失败、中断或达到用量限制时不继续自动续跑。

| 命令 | 操作 |
| --- | --- |
| `/goal <objective>`、`/goal` | 创建或替换目标；查看当前目标。 |
| `/goal edit`、`/goal pause`、`/goal resume`、`/goal clear` | 编辑、暂停、恢复或清除。 |
| `/goal agent-edit [修改要求]`、`/goal agent-edit off` | 授权一次模型编辑并可同时发送要求，或撤销未用的授权。 |

## 模型工具

| `action` | 权限 |
| --- | --- |
| `get` | 只读；返回目标、用量、剩余预算及可用的 `agentEditToken`。 |
| `create` | 仅按用户、system 或 developer 的明确指令创建；没有未完成的目标时可用。只有明确指定时才传 `token_budget`。 |
| `edit` | 提交完整 `objective` 和匹配的 `edit_token`，只修改当前 active 目标的文本。 |
| `update` | 只接受 `complete` 或 `blocked`。前者要求工作全部完成；后者要求同一阻塞至少连续三轮且已陷入僵局。 |

预算耗尽会停止续跑，不代表目标已完成。暂停、恢复和清除由用户命令处理。

## OpenAI 安全拦截恢复

```toml
[goal]
autoCompactOnOpenAISafetyRefusal = true
```

默认开启。Goal 活跃时，如果 `openai` 或 `openai-codex` 的最终错误明确包含 `This content was flagged for possible cybersecurity risk.`，Metis 会调用现有上下文压缩流程，再向 Agent 发送安全提示并继续当前 Goal。压缩摘要保留目标、已验证进展和后续所需证据，不保留重复或规避被拦截操作的指令。

每次恢复后的五个 `agent_start` 请求构成观察窗口，原生重试也计入。连续三次压缩恢复都在各自窗口内再次被拦截时，第四次命中会将 Goal 标记为 `blocked`，不再压缩或续跑；五次请求均未被拦截则退出观察窗口，之后的拦截按新序列计数。计数随 Goal 写入会话分支；手动暂停、恢复、编辑、替换或清除会重置。

该路径只处理明确的网络安全风险错误。普通网络错误、超时、其他提供方、原生重试最终成功以及用户中止均不触发安全压缩。压缩或安全提示入队失败会保留错误并停止自动续跑，不伪造恢复成功。关闭配置后，这类错误沿用普通最终失败处理。配置修改后执行 `/reload`。

## 一次性编辑授权

例如，`/goal agent-edit 保留现有验收条件，再加一项 Windows 验证` 同时授权和发送要求，不必再发一条消息。只输入 `/goal agent-edit` 则只授权。终端会立即提示是否授权成功；目标须处于 active 状态。

获得授权后，模型用 `goal({ action: "get" })` 取授权令牌，再以 `action: "edit"`、完整 `objective` 和 `edit_token` 提交用户明确要求的文本。成功一次即消耗授权。文本不能为空或超过 4,000 字符；无效调用不消费授权。该操作不改变 ID、计时、状态、用量或预算。

手动替换或编辑目标、暂停或结束目标、切换分支、重载和关闭会话都会撤销授权。令牌不是进程沙箱。

## 查看与编辑

全屏点击目标状态或执行 `/goal` 打开弹窗。Ctrl+E 编辑，Ctrl+S 保存，Esc 放弃草稿或关闭。弹窗的清除按钮只在暂停或完成时出现；其他状态可用斜杠命令。RPC 与非交互模式返回文本。

## 用量与续跑

用量归发起该轮的目标，优先采用非缓存输入与输出之和，缺失时使用总 token 数。离线时间不计入。普通续跑只追加目标、用量和简短提醒；首次续跑、第六次及之后每隔五次、编辑目标后，以及压缩、切换分支、重载或解除受阻后的下一次续跑，会附完整审核清单。完成和受阻的判定规则始终不变。过去的续跑消息仍保留发送时的内容；查询当前值请用 `/goal` 或 `goal({ action: "get" })`。后台压缩与续跑的关系见 [Condense](condense.md)。
