# 终端界面

## 输入区

`[appearance.composer]` 控制底色、`>` 提示符与模型信息。提示符和占位文字仅用于编辑界面。模型、提供商、推理级别和上下文用量可在状态栏查看；显示选项见 [配置参考](../configuration.md#显示字段)。

## 任务状态

顶部显示 Pi 和 Metis 版本。输入区上方显示运行、写入或等待输入状态。运行时间包含回答后的历史维护；整轮摘要依据最终状态显示 `Worked`、`Failed`、`Interrupted` 或 `Ended`，并在所有步骤结束后汇总。

`appearance.working` 控制计时、思考、工具和动画。`appearance.summary.persist` 决定是否把摘要存入会话。消息时间按 UTC+8 显示。思考与工具的展开操作见[转录显示](display.md)。

## 统计口径

| 字段 | 含义 |
| --- | --- |
| 上下文 | 当前分支的上下文估算；累计用量见 `Σ`。Condense 发布替换后立即按压缩后的内容估算；使用新上下文的模型回执到达后，恢复 Pi 的回执口径。节省量在替换发布后计入。 |
| `Σ` 输入与输出 | 统计当前会话各分支的 assistant、压缩与分支摘要。 |
| 缓存命中率 | 最近一次确认请求的 `cacheRead / (input + cacheRead + cacheWrite)`。 |
| `gen≈` | 客户端观察到的文本或工具参数生成速度。流式值按字符估算；有提供商用量时以非推理输出校准，计时范围为生成阶段。 |
| Git `+A -D` | 与 HEAD 相比的暂存与未暂存改动，另计未忽略的未跟踪文本。最多计 200 个未跟踪文件，每个最多 256 KiB。 |

Condense 的本地上下文估算不是提供商计数：分词口径可能不同，且本地只能看到远端加密检查点的占位符。请求完成前，状态栏不能确认实际用量。

`/codex-ui` 中的 `out(last)` 是上一个请求的总输出除以请求耗时，包含推理和首字等待；`gen≈` 衡量生成阶段，两者口径不同。账单以提供商为准。

点击状态栏中的三角符号，可单独展开目录或 Condense 的队列状态。默认展开方式由 `appearance.footer.locationExpanded` 和 `pruneExpanded` 决定。

## 全屏历史与留白

全屏模式每页最多显示 5,000 行，并用 `Earlier history` 和 `Later history` 标出前后分页。滚动到页边缘后继续滚动可加载相邻页；搜索只覆盖当前页。分页是显示窗口，会话历史完整保留。

- 点击 **Jump to latest message**、使用底部快捷键，或把滚动条拖到底，可以回到整个会话末尾并跟随新输出。显式跳到最新会清除选区。
- 上方 `↑` 显示已经滚出屏幕的最近一条用户输入。点击可跳回原消息。
- 有选区时，已显示的历史保持原位；解除选区后继续更新。复制及回退方式见[选区复制](selection-copy.md)。

用 `appearance.fullscreen.marginX` 设置两侧留白，设为 0 可关闭留白；分页配置独立。需要终端原生滚动缓冲区时，用 `--tui-mode regular` 启动。

## 字形

`appearance.glyphs.textPresentation` 请求以文本字形显示 `✔ ✖ ✓ ✗ ⚠`。可用 `include` 添加字符；最终效果取决于终端和字体。
