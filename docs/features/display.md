# 转录、工具输出与思考

appearance 只改变显示。参数、结果、模型正文和每次调用的展开状态保持原样。配置见[配置参考](../configuration.md)。生效与退避状态见 `/codex-ui`。

## 命令与探索

```text
• Explored
  └ Read src/server.ts (lines 1–120)
• Ran npm test
  └ Running unit tests...
    … +24 lines (ctrl+o to expand)
    tests passed
```

| 内容 | 规则 |
| --- | --- |
| bash | `Running` 变为 `Ran`。跨行词法高亮，`│` 续行，折叠时占 2 个屏幕行。 |
| 普通输出 | 首行以 `└` 开头，后续行缩进。折叠时占 5 个屏幕行，保留首尾和展开提示。展开后显示全部。 |
| 错误 | 红色前景，证据完整保留。 |
| read、grep、find、ls、neural_search | 显示为 `Exploring` / `Explored`。成功结果默认折叠，各调用独立。 |
| 本包的 exec_command | call 与 bash 共用高亮、换行与复制。结果与后台会话归执行模块。 |

预算按列宽和物理行计算。列宽换算与 UTF-16 长度无关。控制序列只从显示副本中清除。提示跟随宿主的键位。第三方的 Web、MCP、LSP、subagent 与同名工具保留自己的 renderer。图片沿用宿主协议与 `terminal.showImages`。禁用预览时显示图片数量。

## 历史窗口

保留预算、翻页与置顶输入见[界面](interface.md#全屏历史与留白)。边界切入大块时，只保存窗口片段与原始行坐标。追加时复用稳定片段。翻页未命中，或宽度、内容、主题变化时，重建片段。选区期间固定已提交的画面，session 保持只读。

## Codemode

| 部分 | 生成、展开与复制 |
| --- | --- |
| 脚本参数 | 生成过程中，自动预览最后 12 个换行之后的屏幕行，正文灰色，边条橙色 `│`。标题或 JS 正文可在完整脚本与预览之间切换。脚本收齐或中止时，自动收起一次。手动选择优先于之后的更新。脚本生成完成后，展开时恢复 JS 高亮。边条不计入复制内容。预览仅供阅读。 |
| 子调用 | 点击该调用的标题、命令或结果，只切换它自己的参数与结果。状态按真实 ID 保存，同名同参的调用各自独立。沿用普通 renderer、预算和错误样式。 |
| 脚本输出 | 标题、正文与完整路径默认全部隐藏。`Took …` 展开完整可用的输出，可再次收起。已展开的正文单击即可收起。脚本与子调用各自独立，不提供预览。无历史时长时显示 `Took —`。失败时显示红色的 `[error]`。 |
| 调用列表 | 默认显示最近 8 次调用，较早的调用单独切换。手动展开的项在更新时保留。一次 bash（包括管道和复合命令）占用一个块。 |

拖选、滚轮、链接、修饰键以及第三方组件的交互，保持原有语义。全局展开键控制整组，并重置局部状态。regular 模式保留键盘操作路径。运行时已截断的内容，需要读取完整路径查看。

已完成的子结果缓存共用 4 MiB 预算。执行、权限、上下文与重新执行的行为保持原样。切换或关闭会话时清空缓存。历史、重载或超限导致缓存缺失时，会提示并保留摘要。稳定的自有正文（含 Fusion）可以跨父计时刷新复用。标题取当前的 receipt。结果、展开状态、主题或 renderer 变化时，重建并释放旧引用。

## 子代理会话查看器

只读地回放已完成的消息。它与主转录共用 codemode、diff、Fusion、execution 和探索组件。三类展开各自独立。后续命令失败时，之前成功的 diff 修改保留。关闭外观后回退到原生界面。思考块按连续的语义 run 处理。

来源由 child SDK 注册表提供。旧记录或第三方缺少可信来源时，用有界的通用折叠显示。缺少嵌套结果时，如实说明。旧 diff 一律取自归档。缓存、标签、滚动与展开状态相互独立。ACK 归主会话的工具回执。主会话中实时的参数与输出由主视图负责，查看器保持只读。

## 文件修改与 write 预览

- edit 和 write 的 diff 默认从第一处增删起显示 5 个屏幕行。前置上下文、标题和提示不计入预算。点击正文或提示可切换到全量显示（含上下文）。宿主的展开键同样可用。
- 保留行号、增删符号与语法高亮。真彩色的新增与删除背景分别为 `#141e18` 与 `#28140f`。边条 `▎` 占 1/4 格。正文与复制列保持标准宽度。context 行没有底色，续行对齐。256 色等降级方式见[颜色能力](../configuration.md#颜色能力)。
- 高亮与宽度布局分离。文本、语言和宿主颜色版本不变时，resize 与展开复用高亮，只重算布局与复制位置。高亮缓存预算为 4 MiB（UTF-16 容量加条目开销），只保存脱离源缓冲的字符串。超限时淘汰旧项。主题或会话变化时清空。无颜色版本单独计算。语法未就绪时先显示原文，宿主刷新后重试。
- write 使用真实的前后镜像。新文件标记为 Added。可核实的覆盖写显示增删。二进制、过大、不可读、写入后不匹配或 diff 预算不足时，回退到预览。diff 搜索数组的总量限制为 4 MiB。
- 流式 write 保留标题、阶段和尾部。`writePreview.enabled` 控制开关。`rows` 为整块的 0 至 64 个屏幕行，设为 0 时只保留标题与阶段。预览仅供参考，写入结果以工具回执为准。跟踪数据只保存在内存中。
- [Fusion](action-fusion.md) 分别显示修改与命令。命令之后的改写单独入账。已冻结的 diff 保持原样。

## 思考块

`thinking.*` 控制流式与结束时的形态、分隔线与窗口。折叠时显示 `Thought for …`。没有可靠时长时只显示 `Thought`。peek 显示最新已渲染的行。全展开保留全文。

| 操作 | 结果 |
| --- | --- |
| 左键：折叠 → peek → 全展开 | 打开可滚动的 peek。关闭。保持不变。 |
| 右键：折叠或 peek → 全展开 | 全展开。全关闭。 |
| peek 内滚轮 | 滚到边缘时交给正文。回到最新行后恢复跟随。 |
| Shift、Ctrl、Alt 加点击 | 文本选择。 |

主端的命中范围包含整行（留白除外）与相邻的空白，高度与邻近块保持不变。WSL 与 Linux 在右键按下时即生效。Windows 使用宿主的右键路径，避免粘贴时误触。左键在点击时切换。拖选期间保持选区。Ctrl+T 沿用宿主。思考结束后自动切换一次。手动选择优先。

连续的 thinking 构成一个 run。任何非 thinking 的内容（包括空的 text）都会将其分隔。空 run 渲染时跳过。历史时长只取真实值。超大的工具或 run 可能会被完整排版一次，再裁切。
