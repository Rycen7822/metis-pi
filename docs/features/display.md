# 转录、工具输出与思考

appearance 提供紧凑显示，保留工具参数、执行结果、模型正文和各调用的展开状态。配置见 [配置参考](../configuration.md)，实际生效状态见 `/codex-ui`。

## 命令与探索

```text
• Explored
  └ Read src/server.ts (lines 1–120)
• Ran npm test
  └ Running unit tests...
    … +24 lines (ctrl+o to expand)
    tests passed
```

| 内容 | 显示规则 |
| --- | --- |
| bash 命令 | `Running` → `Ran`；换行前高亮，词法状态跨行保持，续行用 `│`，折叠预算 2 个屏幕行。 |
| 普通输出 | 首行 `└`，其余缩进；折叠预算 5 个屏幕行，长输出保留首尾与展开提示，展开后为完整正文。 |
| 错误 | 前景标红，保留错误证据。 |
| read / grep / find / ls / neural_search | `Exploring` / `Explored`，成功结果默认折叠，各结果仍独立。 |
| 本包 exec_command | 命令 call 共用 bash 换行、高亮和复制信息；结果布局和后台会话由执行模块负责。 |

展开提示跟随宿主键位。预算按终端列宽和物理行计算，不按 UTF-16 长度裁列；控制序列仅在显示副本中清理。第三方 Web、MCP、LSP、subagent 或同名工具保留 renderer。图片使用宿主协议并服从 `terminal.showImages`，关闭预览只报数量，不输出 Base64。

## 历史窗口

历史窗口的保留行数、翻页与置顶输入见 [界面](interface.md#全屏历史与留白)。渲染侧边界切到大块中间时，仅缓存窗口内片段及原始行坐标，不保留隐藏部分的整块排版或复制缓存。
追加结果可复用未变化的片段；翻页需要未缓存区域、宽度变化、内容更新或主题失效时按需重建。选择中的已提交画面、复制和鼠标定位保持稳定，不修改会话数据。

## Codemode

- 脚本参数生成中自动显示最新 12 个屏幕行，长行换行后再取尾部；正文使用思考文字的灰色，左侧细边条与 `codemode` 标题同为橙色，不对每个增量做整段 JS 高亮。
  点击 `codemode` 标题或 JS 正文可查看完整的生成中脚本，仍使用灰色正文，再点击回到预览。参数收齐后立即自动折叠一次，不等执行结束；之后的执行更新不会覆盖手动展开选择。
  再次展开已生成脚本时保留橙色边条与原有 JS 高亮；边条仅作装饰，不进入语义复制。
  历史结果不当成正在生成的脚本，生成中止也会结束自动预览；预览不执行脚本或修改参数。
- fullscreen 中左键点击已生成脚本的 `codemode` 标题或 JS 正文只展开/收起脚本；点击某次子调用的工具标题、命令或结果正文，只切换该次调用的参数、命令与结果，按真实调用 ID 独立保存，同名/同参数调用不串状态。嵌套工具沿用普通 renderer、折叠预算与错误显示；正文点击不切换整组，拖选、滚轮、链接及第三方组件交互保持原样。
- `Script output` 的标题、正文和完整输出路径默认全部隐藏；左键点击底部 `Took …` 完整展开可用输出，再点击收起，不保留预览。
  输出标题和正文点击不切换开关，也不影响脚本或子调用。缺少可靠历史耗时时用 `Took —` 保留入口；脚本失败仍在底部显示红色 `[error]`。
- 较早调用列表单独切换；默认显示最近 8 次调用，已手动展开的旧调用在流式更新时保持可见。
  原有全局展开快捷键仍展开/折叠整组并重置局部选择，普通终端模式保留该键盘路径；运行时已截断的脚本输出仍需通过完整输出路径读取。
  一次 bash 调用（含 `&&`/管道等复合命令）作为一个块，不按子命令拆分输出。
- 仅缓存当前会话已完成的子结果用于显示，不改变执行、权限或模型上下文。缓存预算 4 MiB，会话更换/关闭时清空；历史、重载或超限时提示缺失并保留摘要，不重执行。
  未变化的本包子结果正文在父计时刷新时复用，包括提供 `then_run` 能力的 Metis edit/write 入口；调用标题仍读取当前 receipt。
  结果、展开状态、主题或实际 renderer 变化后重建，缓存失效同时释放复用信息。

## 文件修改与 write 预览

- diff 显示行号、增删符号和正文；增删行使用整行底色，context 无底色，续行对齐正文。颜色降级见 [配置](../configuration.md#颜色能力)。
- 语法高亮与按宽度排版分离：resize、展开切换可复用同文本、语言及宿主颜色版本的高亮，仍重新计算布局与复制位置。
  独立高亮缓存按 UTF-16 容量及条目开销估算，预算 4 MiB，仅保存脱离源缓冲区的字符串；超限淘汰旧条目，主题、会话切换或关闭清空。
  不具备宿主颜色版本的 painter 不参与复用；Pi 语法尚未加载时 diff 暂用原文，语法就绪后由宿主刷新重试。
- write 捕获真实执行前后镜像：新文件显示 Added，覆盖写在可核实时显示增删。二进制、过大、不可读、post 不匹配或 diff 预算不足时回退内容预览；diff 搜索数组合计上限 4 MiB。
- 流式 write 显示标题、阶段与尾部正文；`writePreview.enabled` 开关预览，`writePreview.rows`（0–64）控制整块屏幕预算，0 只保留标题和阶段。预览不表示内容已经写入，跟踪状态只存内存。
- [Action Fusion](action-fusion.md) 分开显示修改和命令；命令后改写文件不会污染已冻结的修改 diff。

## 思考块

流式形态、结束形态、左侧分隔线和窗口行数由 `thinking.*` 控制。折叠显示 `Thought for …`，缺可靠时长时仅显示 `Thought`；窥视显示最新已渲染行，全展开保留整段正文。

| 操作 | 结果 |
| --- | --- |
| 左键点击折叠块 / 窥视块 | 打开可滚动窥视 / 关闭。 |
| 左键点击全展开块 | 保持全展开，不改变状态。 |
| 右键点击折叠或窥视块 / 全展开块 | 完全展开 / 完全关闭。 |
| 窥视窗内滚轮 | 窗口内滚动，到边缘交回正文；回到最新行恢复跟随。 |
| Shift/Ctrl/Alt 点击 | 交给文本选择。 |

主会话的点击范围覆盖块的整行宽度（不含全屏留白），以及紧邻的已有空白行；不增加显示高度，也不侵占相邻正文或工具。
WSL/Linux 的右键在按下时立即生效，不依赖终端上报松开事件；原生 Windows 保留宿主点击路径，避免误触发右键粘贴。左键仍在点击时切换，拖选不切换状态。
不等待或识别双击；进行中和结束块规则相同，`ctrl+t` 保留宿主全局行为。结束自动切换一次，用户后续选择不会被重建覆盖。

连续 thinking 块形成语义 run，任何非 thinking 块（含空 text）切开 run；全空 run 不生成组件，历史时长不伪造。单个超大工具组件或思考 run 仍可能完整排版一次后裁切。
