# 转录、工具输出与思考

appearance 保留参数、结果、模型正文及逐调用展开状态，仅改变显示。配置见[配置参考](../configuration.md)，生效/退避见 `/codex-ui`。

## 命令与探索

```text
• Explored
  └ Read src/server.ts (lines 1–120)
• Ran npm test
  └ Running unit tests...
    … +24 lines (ctrl+o to expand)
    tests passed
```

| 内容 | 规则 |
| --- | --- |
| bash | `Running` → `Ran`；跨行词法高亮、`│` 续行，折叠 2 屏幕行。 |
| 普通输出 | 首行 `└`，后续缩进；折叠 5 屏幕行，保留首尾与展开提示，展开后完整。 |
| 错误 | 红色前景，证据保留。 |
| read / grep / find / ls / neural_search | `Exploring` / `Explored`；成功结果默认折叠，各调用独立。 |
| 本包 exec_command | call 共用 bash 高亮/换行/复制；结果和后台会话归执行模块。 |

预算按列宽/物理行，不以 UTF-16 裁列；控制序列只清理显示副本，提示跟随宿主键位。第三方 Web/MCP/LSP/subagent/同名工具保留 renderer。图片沿用宿主协议及 `terminal.showImages`，禁预览只报数量，不输出 Base64。

## 历史窗口

保留预算、翻页、置顶输入见[界面](interface.md#全屏历史与留白)。边界切入大块时只存窗口片段和原行坐标，不留隐藏整块排版/复制缓存；追加复用稳定片段，翻页 miss、宽度/内容/主题变化才重建。选区期间固定已提交画面，不改 session。

## Codemode

| 部分 | 生成、展开与复制 |
| --- | --- |
| 脚本参数 | 生成中自动预览最后 12 个换行后屏幕行：灰色正文、橙色 `│`，不逐增量高亮整段 JS。标题/JS 正文切换完整脚本与预览，收齐或中止时自动收起一次；后续更新不覆盖手动选择。已生成脚本展开恢复 JS 高亮；边条不复制，预览不执行或改参数，历史不当作流式脚本。 |
| 子调用 | 点击该调用标题/命令/结果只切换自己的参数与结果；按真实 ID 保存，同名同参不串状态，不切整组。沿用普通 renderer、预算和错误样式。 |
| Script output | 标题/正文/完整路径默认全藏；`Took …` 展开完整可用输出并可再收起，已展开正文也可单击收起。不影响脚本/子调用，无预览；无历史时长保留 `Took —`，失败保留红色 `[error]`。 |
| 调用列表 | 默认最近 8 次，较早调用单独切换，手动展开项更新时保留。一次 bash（含管道/复合命令）只占一个块。 |

拖选、滚轮、链接、修饰键及第三方组件交互不误折叠。全局展开键仍控制整组并重置局部状态，regular 保留键盘路径；运行时已截断内容须读完整路径。

已完成子结果缓存共用 4 MiB 预算，不改变执行、权限、上下文或重执行；会话切换/关闭清空，历史/重载/超限缺失时提示并保留摘要。稳定的自有正文（含 Fusion）可跨父计时刷新复用，标题仍取当前 receipt；结果/展开/主题/renderer 变化重建并释放旧引用。

## 子代理会话查看器

只读回放已完成消息，共用主转录的 codemode/diff/Fusion/execution/探索组件，三类展开独立；后续命令失败不抹掉成功修改。关闭外观回退原生，思考按连续语义 run 处理。

来源由 child SDK 注册表提供；旧记录/第三方缺可信来源时用有界通用折叠显示，缺嵌套结果明确说明，不读当前文件伪造旧 diff 或重执行。缓存、tab、滚动/展开独立，打开/关闭不消费 ACK；不订阅主会话实时参数/输出、不绘终端图片、不复制主输入区布局。

## 文件修改与 write 预览

- edit/write diff 默认从首条增删起显示 5 屏幕行，前置上下文、标题和提示不占预算；点击正文/提示切全量（含上下文），宿主展开键保留。
- 保留行号、增删符号与语法亮度；真彩新增/删除背景为 `#141e18` / `#28140f`，边条 `▎` 为 1/4 格，正文/复制列不变。context 无底色、续行对齐；256 色近似和其他降级见[颜色能力](../configuration.md#颜色能力)。
- 高亮与宽度布局分离：文本/语言/宿主颜色版本不变时 resize/展开可复用高亮，重新算布局/复制位置。缓存预算 4 MiB（UTF-16 容量+条目开销），只留脱离源缓冲的字符串；超限淘汰旧项，主题/会话变化清空。无颜色版本不复用，语法未就绪先原文、宿主刷新重试。
- write 使用真实前后镜像：新文件 Added，可核实覆盖写显示增删。二进制、过大/不可读、post 不匹配或 diff 预算不足回退预览；diff 搜索数组合计限 4 MiB。
- 流式 write 保留标题/阶段/尾部；`writePreview.enabled` 控制开关，`rows` 为整块 0–64 屏幕行，0 只留标题/阶段。预览不是写入成功证据，跟踪仅在内存。
- [Fusion](action-fusion.md) 分开显示修改与命令，命令之后的改写不污染已冻结 diff。

## 思考块

`thinking.*` 控制流式/结束形态、分隔线与窗口。折叠显示 `Thought for …`，缺可靠时长只显示 `Thought`；peek 是最新已渲染行，全展开保留全文。

| 操作 | 结果 |
| --- | --- |
| 左键：折叠 / peek / 全展开 | 打开可滚动 peek / 关闭 / 保持不变。 |
| 右键：折叠或 peek / 全展开 | 全展开 / 全关闭。 |
| peek 内滚轮 | 到边缘交正文，回最新行恢复跟随。 |
| Shift/Ctrl/Alt 点击 | 文本选择。 |

主端命中范围含整行（不含留白）和相邻已有空白，不增高度/侵占邻块。WSL/Linux 右键按下即生效，不等松开；Windows 保留宿主路径，避免粘贴误触。左键在 click 切换，拖选不切换，不识别双击；Ctrl+T 沿用宿主。结束自动切换一次，不覆盖后续手动选择。

连续 thinking 构成 run，任何非 thinking（含空 text）切开；空 run 不渲染，历史不伪造时长。超大工具或 run 仍可能完整排版一次再裁切。
