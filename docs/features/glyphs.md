# 字形文字呈现

部分符号会被终端选用 emoji 字体绘制，笔画可能覆盖相邻字符。metis-pi 在帧写入终端前，为指定符号补充 U+FE0E（VS15），请求文字形态。

## 显示规则

- 默认字符为 `✔ ✖ ✓ ✗ ⚠`。仅对没有显式选择子的字符追加 VS15；已有 U+FE0F（VS16，emoji 形态）或 VS15 均保持原样。
- 修改发生在布局之后，pi-tui 将选择子计为零宽，因此不改变布局的列映射。会话记录和选区复制文本不加入这个选择子。
- SGR、OSC 8 链接及 OSC 52 剪贴板载荷原样通过，控制序列里的字符不替换。
- `✅`、`❌`、`🔴` 等符号不在默认集合中。实际字形仍取决于终端和字体是否支持对应文字呈现，不能保证所有环境都按相同宽度绘制。

## 配置与范围

| 配置 | 效果 |
| --- | --- |
| `glyphs.textPresentation: false` | 关闭转换 |
| `glyphs.include: ["⏺"]` | 追加字符；每项须为单个非 ASCII 字符，非法项跳过并记录 problem；去重后最多 32 项 |

只覆盖已安装的帧写入路径；直接绕过该路径写终端的组件不受影响。完整键表见 [配置](../configuration.md)。

实现为 `src/glyph-presentation.ts`，安装在 `src/chrome/install.ts`。核心测试验证真实 `visibleWidth` 与写入内容，严格 PTY 验证复制文本未被选择子污染；证据见 [VALIDATION](../../VALIDATION.md)。
