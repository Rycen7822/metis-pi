# 选区复制

在全屏模式中拖选，再按 Ctrl+C（或 Pi 的 `app.clear` 绑定）。复制会合并终端软换行，保留原文的换行与缩进，不包含纯装饰的行号和边栏。未选中文字时，按键仍交给 Pi。普通模式下使用终端自身的选区，如 Shift 拖拽。

| 情况 | 结果 |
| --- | --- |
| 选中文字 | 写入剪贴板，保留输入草稿。 |
| 只选中行号、边栏或省略提示 | 不修改剪贴板或草稿。 |
| 剪贴板写入失败 | 保留选区与草稿。 |
| 表格、图片或无法匹配原文的行 | 交给 Pi 提取显示文本；可能保留屏幕换行。 |

用 `[appearance.selectionCopy]` 中的 `enabled` 控制逻辑提取，`ctrlC` 控制快捷键。`/codex-ui` 报告 `exact`、`mixed` 或 `native-fallback`，见[诊断](../diagnostics.md)。

## 删除输入框选区

选区完全位于全屏输入正文内时，Backspace 或 Delete 会删除整段，可以撤销一次恢复。相交的粘贴占位符会作为整块删除。选区跨出输入框，或无法与当前草稿对应时，按普通删除键处理。此操作不受复制开关控制。

## 剪贴板

本地 WSL 在未使用 Windows Terminal、SSH 或 MOSH 时尝试直写 Windows 剪贴板。初始化或写入失败时使用 Pi 的路径。其他环境以及 `PI_CLIPBOARD_OSC52=1` 均使用 Pi 原生剪贴板处理。
