# 选区复制

在全屏模式中拖选，再按 Ctrl+C（或 Pi 的 `app.clear` 绑定）。复制会合并终端软换行，保留原文的换行与缩进；装饰性行号和边栏会被排除。空选区时，按键交给 Pi。普通模式下使用终端自身的选区，如 Shift 拖拽。

| 情况 | 结果 |
| --- | --- |
| 选中文字 | 写入剪贴板，保留输入草稿。 |
| 只选中行号、边栏或省略提示 | 剪贴板与草稿保持原值。 |
| 剪贴板写入失败 | 保留选区与草稿。 |
| 表格、图片或无法匹配原文的行 | 交给 Pi 提取显示文本；可能保留屏幕换行。 |

正文流式输出时，精确复制所需的文字映射按需生成，回复生成期间即可复制。

用 `[appearance.selectionCopy]` 中的 `enabled` 控制逻辑提取，`ctrlC` 控制快捷键。`/codex-ui` 报告 `exact`、`mixed` 或 `native-fallback`，见[诊断](../diagnostics.md)。

## 删除输入框选区

在 Metis 全屏输入框内，Backspace 或 Delete 可删除拖选、双击选中的内容；撤销一次即可恢复。粘贴占位符与选区相交时，整个占位符一并删除。

此操作只处理应用内选区；终端自身的选区（例如 Shift 拖拽）由终端管理。选区跨出输入框或缺少当前草稿映射时，按键执行普通删除。删除功能独立于复制开关。

## 剪贴板

本地 WSL 在未使用 Windows Terminal、SSH 或 MOSH 时尝试直写 Windows 剪贴板。初始化或写入失败时使用 Pi 的路径。其他环境以及 `PI_CLIPBOARD_OSC52=1` 均使用 Pi 原生剪贴板处理。
