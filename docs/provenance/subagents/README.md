# Subagent core provenance

The native subagent core and its behavioral fixtures are derived from
https://github.com/Rycen7822/subagent-pi at commit
`4765456f62bbec2724743e17855c4e21f5f6d6d8` (0.5.0).

The source now belongs to metis-pi under `src/subagents/core`; it is maintained
and released with metis-pi. No external subagent runtime package is required.
The MIT license and third-party notices are retained alongside this document.
